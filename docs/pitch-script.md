# AgentPay — 1-minute pitch script

**0:00-0:12**

AI agents can plan, reason, and act. But they still can't pay each other for data or compute.

> AIエージェントは計画し、推論し、行動できます。しかし、まだ互いにデータや計算の対価を支払うことができません。

**0:12-0:28**

Today, paying for an API means human-in-the-loop billing: keys, invoices, manual approval. That breaks autonomous agents.

> 現在、APIの支払いには人間の承認が必要です。APIキー、請求書、手動承認。これは自律型エージェントの仕組みを壊します。

**0:28-0:42**

AgentPay fixes this. It wraps any API with a 402-style paywall. An agent gets a price, pays in USDC on Solana, and gets the response, instantly.

> AgentPayはこれを解決します。どんなAPIも402形式のペイウォールで包みます。エージェントは価格を受け取り、ソラナ上でUSDCを支払い、即座に応答を得ます。

**0:42-0:52**

Every paid call mints an on-chain receipt. Our demo marketplace shows agents buying search, image generation, and data feeds from each other.

> 支払いごとにオンチェーンの領収書が発行されます。デモのマーケットプレイスでは、エージェント同士が検索、画像生成、データを売買します。

**0:52-1:00**

AgentPay is the payment rail for the agent economy. Thank you.

> AgentPayはエージェント経済のための決済基盤です。ご清聴ありがとうございました。
